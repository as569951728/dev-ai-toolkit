## Release Procedure

1. Complete every hard gate or record why the release must remain blocked.
2. Create `release/v0.2.0` from the selected green `main` commit.
3. Limit the release branch to version and documentation corrections.
4. Open a pull request back to `main` and run the complete checks again.
5. Tag the merged commit as `v0.2.0`; do not tag an earlier branch-only SHA.
6. Create the GitHub Release from `docs/releases/v0.2.0.md`.
7. Recheck the demo and installation instructions after publishing.
8. Add the final SHA, CI run, release URL, and verification date below.

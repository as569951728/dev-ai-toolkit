# v0.1.0

Released on 2026-05-06.

This was the first tagged release of `dev-ai-toolkit`. It introduced a
browser-based prompt workspace and three supporting developer utilities built
with React, Vite, and TypeScript.

## Included

### Prompt workflows

- Create, edit, duplicate, delete, search, and filter prompt templates
- Import and export prompt templates as JSON
- Compose template variables and preview prompts in Prompt Playground
- Compare prompt text in Prompt Diff
- Restore a prompt template from its local revision history
- Save prompt snapshots and reopen recent runs from the Playground

### Developer utilities

- Format, validate, and minify JSON
- Draft HTTP request configurations and generate `fetch` snippets
- Review text or code in single and compare views

### Project setup

- Feature-based React application structure
- Local repository and service layers for templates and prompt runs
- GitHub Actions checks for lint, tests, and production builds
- Unit tests for core services and one prompt workflow smoke test
- English and Simplified Chinese README files
- Initial architecture and planning documents under `docs/`

## Known limitations

- Data is stored in the active browser profile through `localStorage`
- There is no backend, account system, or cross-device synchronization
- Saved prompt runs do not have a dedicated history page in this release
- JSON Tools, API Builder, and Code Viewer are mostly standalone utilities
- Workspace backup and run notes are not included

## Planned after v0.1.0

- Add a dedicated history view for saved prompt runs
- Expand workflow-level regression coverage
- Define clearer persistence and schema migration boundaries
- Improve issue, pull request, deployment, and release maintenance
- Connect supporting utilities to the prompt review workflow where useful

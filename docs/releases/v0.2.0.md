# v0.2.0 (Draft)

**Status:** Release candidate not selected

These notes describe the user-visible work currently on `main` after `v0.1.0`.
They are not final release notes. The candidate SHA, release date, and deployment
evidence will be added only after the
[release readiness checklist](../maintenance/v0.2.0-release-readiness.md) passes.

## Summary

`v0.2.0` develops the original local prompt workspace into a more complete
template-to-review workflow. Saved prompt snapshots now have a dedicated
history, review notes, comparison and reuse actions, and manual workspace
backup. The release also strengthens browser-storage failure handling and
connects supporting tools to saved prompt context.

The project remains a browser-only, local-first tool. This release does not add
a backend, account system, cloud synchronization, model execution, or agent
orchestration.

## Highlights

### Saved Prompt Review

- Browse saved prompt snapshots in Run History with template filters, age
  sorting, prompt and note search, and captured variable previews.
- Add a local review note, copy complete labeled prompts, compare a snapshot
  with its matching template revision, or reopen its variables in the
  Playground.
- Export or import one saved run with its note context, delete stale snapshots,
  or use a snapshot as the starting point for a new template draft.
- Compare historical template revisions with the current template without
  putting prompt content in the URL.

### Local Workspace Reliability

- Export and preview a versioned workspace backup containing templates, saved
  runs, notes, and recent Playground shortcuts before importing it.
- Refresh local collections across tabs while protecting visible unsaved
  template and note drafts.
- Download unreadable local collection bytes before explicitly resetting the
  affected data.
- Report browser-storage, clipboard, import, and export failures in the app
  instead of leaving the result ambiguous.
- Roll back related run data and multi-collection workspace writes when a later
  import step fails, and report when rollback cannot be completed fully.
- Reject oversized template, run, and workspace JSON files with a shared 5 MB
  limit before reading their full contents.

### Connected Developer Utilities

- Open captured run variables in JSON Tools and saved prompts in Prompt Diff or
  Code Viewer without exposing prompt content in shareable URLs.
- Copy complete prompts from the Playground, Run History, or Run Detail.
- Generate and copy cURL commands from API Builder alongside existing `fetch`
  snippets.

### Keyboard And Maintenance Baseline

- Skip primary navigation with the keyboard, keep focus visible, honor reduced
  motion, and expose one page-level heading on each application route.
- Run dependency auditing, coverage thresholds, production builds, and browser
  smoke tests through the protected GitHub Actions `quality` check.
- Keep English and Simplified Chinese setup, current scope, local data, and
  limitation guidance in matching README sections.

## Data Compatibility

Candidate verification of existing `v0.1.0` browser data is still required
before release. No manual migration should be assumed until that check passes.

Before testing this draft against important local data, export a Workspace
Backup from the existing version. Recovery downloads preserve unreadable raw
collection bytes, but they are diagnostic files and are not guaranteed to be
importable workspace backups.

## Known Limitations

- Templates, snapshots, notes, and recent shortcuts are stored in
  `localStorage` for one browser profile.
- There is no automatic backup, account recovery, multi-device sync, or server
  API.
- Local storage is not encrypted. Prompts, notes, and API drafts should not
  contain production secrets or access tokens.
- Cross-tab updates use the browser's last persisted write. Draft warnings do
  not merge concurrent field-level edits.
- JSON imports accept the project's supported versioned formats and are limited
  to 5 MB per file.
- Workspace Backup is a manual transfer mechanism, not continuous sync.
- API Builder creates request examples but does not send requests.
- Prompt execution still happens in an external AI tool; this project does not
  call a model provider.
